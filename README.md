# mcpharden has moved into mcpscan

`mcpharden` is now the **`mcpscan harden`** module of the [**mcpscan**](https://github.com/cognis-digital/mcpscan) security suite — scan, harden, gate, and pin your MCP servers from one command.

```bash
pip install cognis-mcpscan
mcpscan harden --help      # the standalone `mcpharden` command still works too
```

This repository is **archived (read-only)**. All development continues in [mcpscan](https://github.com/cognis-digital/mcpscan). Nothing was lost — every feature and command lives on there.
